# PakWheels Used Car Market Analysis

## Overview
A Python-based analysis of Pakistan's used-car listings using a dataset originally published on Kaggle. The project explores vehicle characteristics, asking prices, and market patterns through data cleaning, feature engineering, and exploratory data analysis.

## Dataset
- **Source:** [Pakistan Used Car Prices 2023 – Kaggle](https://www.kaggle.com/datasets/talhabarkaatahmad/pakistan-used-car-prices-2023)
- **Original uploader:** Talha Barkaat Ahmad
- **Data origin:** PakWheels listings, as described by the dataset uploader.

The original CSV is not included in this repository. Please obtain the dataset directly from its original source. Dataset redistribution permissions have not been independently verified.

## Objectives
- Clean and prepare raw vehicle listing data.
- Create useful features for analysis.
- Explore relationships between vehicle characteristics and asking prices.
- Identify patterns across brands, fuel types, mileage categories, and cities.
- Develop practical business recommendations.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. **Data Exploration:** Examine dataset structure and descriptive statistics.
2. **Data Cleaning:** Handle missing values, data types, duplicates, and invalid records.
3. **Feature Engineering:** Create vehicle age, price in lakhs, and mileage categories.
4. **Exploratory Data Analysis:** Visualize price distributions, correlations, and category comparisons.
5. **Business Insights:** Summarize findings and suggest pricing and inventory strategies.

## Key Findings
- Toyota, Suzuki, and Honda account for the largest number of listings.
- Vehicle mileage and age generally have negative relationships with asking prices.
- Engine capacity has a positive relationship with asking prices.
- Median asking prices vary across fuel types, transmission categories, and cities.

## Note
This is an academic Business Data Analysis project. The dataset contains advertised prices, not confirmed transaction prices. Findings describe patterns in the available listings and should not be interpreted as definitive measures of actual market demand or completed sales.
